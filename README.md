# Find Partner: Matrimony & Matching App (Flutter)

**A matrimony and matching app where members create detailed profiles, search with filters and connect with suitable matches.**

Built by [Oriental Tech Solutions](https://github.com/OrientalTechSolutions) · Flutter · iOS & Android

---

## What we built

- **Detailed profiles:** photos, age, location, education, profession and an "About me" section
- **Discover:** browse members, nearby and newest members
- **Search filters:** age range, location, education, profession, marital status and more
- **Like or pass** on profiles
- **Online status** and profile photo galleries

## Tech stack

`Flutter` `Dart` `Firebase` `REST API` `Push notifications`

## Our role

UI implementation, app development, search and matching features, testing and release.
